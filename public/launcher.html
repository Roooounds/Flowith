What is Flowith?
A node-based multi-agent AI workflow manager. Connect task nodes on a canvas to build complex AI pipelines — like a visual programming language for LLMs. Local-first means your data never leaves your machine.
🔷
Node Types
Input — define data sources · Task — AI processing step · Logic — merge or route · Decision — yes/no branching · Switch — multi-branch routing · Loop — iterate until condition met · Output — display results
🎭
Agents (Roles)
Create AI personas with custom System Prompts, model selection, and tool permissions. Assign different agents to different task nodes — like a team of specialists. Supports Ollama (local), OpenAI, Anthropic, and Gemini.
⚡
Running Workflows
Click Run All to execute the entire graph. Nodes run in order based on dependencies (topological sort). Execution caching skips nodes whose inputs haven't changed — saving compute and time.

Pro Tips
• Drag nodes from the left toolbar, or right-click the canvas to add.
• Connect nodes by dragging from a bottom handle to a top handle.
• Use the Task Chat panel to iteratively refine AI outputs.
• Switch between Dark / Light themes in Settings.
